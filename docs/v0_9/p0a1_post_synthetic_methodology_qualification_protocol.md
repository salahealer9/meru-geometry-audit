## 3. Explicit representation ontology — M1

Construct an **information-availability and observability matrix** with at least these distinct objects:

- `R3-C`: ordered sampled 3-D centreline(s), with parameterization, orientation, closure and curve count if justified;
- `R3-S`: finite-width 3-D surface/mesh or ribbon, with lighting/occlusion material model if specified;
- `R2-O`: projected *ordered* 2-D path(s), retaining known point correspondence, stroke direction and endpoints;
- `R2-U`: unordered sampled 2-D geometric support, losing order, labels and often topology;
- `R2-G`: supplied 2-D stroke graph (vertex identities, components, stroke partition, endpoints/junctions);
- `R2-I`: finite-resolution raster/ink union, with fixed width, window, supersampling and threshold;
- `R2-H`: actual historical hand/ribbon **shadow**, requiring a physical carrier and projection/occlusion law not certified by P0A0.

For each representation write: observable fields, information lost in conversion, valid source objects, valid target objects, transformation nuisance group, normalization obligations, numerical degeneracies, whether source provenance supplies the required fields, and whether the target would need a *new* source-licensed extraction convention.

**Forbidden equivalences:** a 3-D centreline shadow ≠ a 3-D ribbon/hand shadow; ordered path ≠ unordered support; sampled point cloud ≠ continuous curve; geometric components ≠ labelled stroke components; raster pixel connectivity ≠ exact topology; a hand-drawn A09 shadowgram ≠ exact metric observation of a physical sculpture. No inference from missing labels is permissible without a separately identified segmentation model and its uncertainty.

**Cross-representation comparisons** require a declared forward operator (for example `R3-C → R2-O → R2-I`) with all width, sampling, direction, alignment and discretization parameters fixed *before* Hebrew input. Do not compare mathematically incompatible objects by pretending their coordinates mean the same thing.

## 5. Symmetry, chirality and alignment contract — M3

Specify mathematical nuisance groups **before** any score:

1. Translational alignment: use a declared and reproducible centering rule.
2. Positive planar scale `s>0` only where permitted; no negative scale to disguise reflection or collapse a target. Define any zero-/near-zero-extent exclusion separately.
3. In-plane proper `SO(2)` rotation as the **proposed primary chirality-preserving orientation convention** for later design. An `O(2)` reflection-permitting treatment is a distinct **sensitivity analysis**, not free additional views and not an undiscussed default. If the historical observation calls for mirroring, demand source-backed justification and an explicit later preregistration.
4. Open-curve traversal reversal only where physically/observationally meaningless and explicitly registered; cyclic shift **only** for genuinely closed paths. No unregistered path truncation, arbitrary piece deletion, reconnection, repartition or choice of preferred stroke fragment.
5. Multiple-stroke correspondence, component permutation, endpoint matching or masking are **additional discrete optimization capacities**. They must be frozen, counted/bounded and justified separately rather than concealed inside the metric.
6. Similarity fitting (translation, scale and permitted rotations) and camera selection are distinct optimization axes. Count the combined search freedom when interpreting match prevalence. Nothing may be optimized against *target identity* and then treated as an independently prescribed parameter.

Write explicit group action, quotient relation, and tie-breaking policy for each representation. Clearly distinguish a transformation that preserves observables from one that only reduces a numerical distance. S02 and S09 are mandatory counterexamples for accidental over-permission.

**Do not reinterpret S12's signed-versus-unoriented collapse as evidence that SO(2) and O(2) are interchangeable.** Their difference is mathematically and scientifically material.

## 7. Viewing freedom, effective capacity and fairness — M5

Define viewing frames `R∈SO(3)` and camera direction `n=R^T e_z`. Under orthographic projection with a free in-plane `SO(2)` quotient, two frames with the same signed `n` differ only by axial camera roll and are not two effective viewpoints. Opposite directions are *not* generally equivalent under SO(2); they can become equivalent under an explicitly allowed `O(2)` reflection quotient. Object-specific symmetries can further collapse classes and must be labeled **object-specific**, never confused with the universal camera-direction count.

**G0 methodological anchor:** inherited tetrahedral group of twelve proper frames; exactly **six signed camera directions**, with **three unoriented axes only when that quotient is explicitly used**. Any G0 analysis must state the planar symmetry convention and the object class/closure semantics. Do not multiply the view count by redundant roll angles.

**G1/G2 remain unchosen in P0A1**. Develop a **capacity design rule**, not unsupported numerical tiers:

- each level must specify a finite, reproducible set of **distinct signed physical directions** or a continuous domain with a certified discretization/optimization policy;
- levels for a monotonicity claim must be **nested in the same physical orientation and matching group**, `G0⊆G1⊆G2`, with strictly increased quotient-distinct capacity where asserted;
- camera directions, quadrature/grid construction, angular resolution, generator hashes and tie breaking are to be frozen **later and before Hebrew target access**; projected same-object duplicates can be recorded as an object-specific adjustment, not used to tune a target result;
- reflect/roll/scale/translation/stroke fragmentation freedoms must be logged **separately** from the number of camera directions. Do not imply that more nominal orientations always add independent matching opportunity;
- for a fixed object, target, metric and nested admissible transformations, `min_(g∈G2) E(g) ≤ min_(g∈G1) E(g) ≤ min_(g∈G0) E(g)`. This deterministic multiple-opportunity effect applies equally to candidate and control; a smaller minimum by itself proves no object specificity;
- null controls and candidate objects must have exactly the same registered search budget, error metric, alignment allowances, optimizer accuracy and stopping rule for each level; if the source constrains views differently, specify a separately analyzable constrained-vs-matched comparison rather than silently unequal capacities.

P0A1 deliverable: an unambiguous **method to count, report and equalize effective capacity** (including per-object optional extra equivalences), plus an explicit list of the remaining numerical G1/G2 choices. It does **not** decide those numerical sets or run a view sweep.

## 8. Optimization reliability and independent certification — M6

S11 rejects a generic claim of global reliability for a locally converged bounded solver: observed local objective **0.4**, analytic global objective **0**.

For every *future* objective family considered, require a solver-qualification ledger specifying:

- domain (finite or compact continuous), parameterization, noncompact/degenerate exclusions, continuous vs discrete nuisance dimensions, reflection and order choices;
- analytical symmetries and exact finite-enumeration reductions usable **without** target data;
- independent reference oracle: exact global proof, certified interval/lower bound, exhaustive finite enumeration, or stated deterministic error bound with proof of completeness; multistart alone is **not** a certificate;
- optimizer tolerance, tie behavior, failure state, reproducibility, runtime limits, a genuine `GLOBAL_CERTIFIED` vs `BOUNDED_APPROXIMATION` vs `LOCAL_ONLY` status;
- a procedure for a bounded solver discrepancy against an independent reference **without** retuning using Hebrew results; and a stop/phase-amendment path if any claimed global property remains unproved.

No P0A1 model is allowed to claim global optimization certification merely by summarizing P0A0. No new optimizer is run by this phase. A later separately frozen synthetic stress-test/certification may be necessary before the first candidate-vs-null comparison.
