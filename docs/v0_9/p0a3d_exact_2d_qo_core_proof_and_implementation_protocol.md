## 1. Binding mathematical input and nuisance contract

**Inputs:** exactly two independently supplied **ordered open polygonal paths** `a` and `b`, each represented by a finite list of at least two vertices in `Q²`. Encode each rational component canonically as signed integer numerator and strictly positive integer denominator (reduce by gcd); do not interpret binary64 or a rounded decimal as an exact rational input. Finite declared maximum input sizes/bit lengths apply to *DEV resource budgets*, not to the mathematical definition.

**Path interpretation:** endpoints and traversal order are fixed metadata. A path is a continuous piecewise-linear map on an interval with one ordered traversal; it is **not** a finite unordered support. Consecutive duplicate vertices contribute zero arclength and may be reduced **only** with a preserved provenance event log. Nonconsecutive returns and retracing preserve their traveled arclength multiplicity. The first and last coordinates may coincide while the parameter interval still has distinguished ends; this does not grant closed-curve cyclic phase search. Subdivision of an existing straight traversal by new collinear intermediate vertices is geometrically equivalent; arbitrary independent vertex sampling is not given correspondence.

**Eligibility:** each input has positive total Euclidean arclength and strictly positive arclength-measure RMS radius. Invalid rational syntax, dimension, sequence or missing independent traversal metadata is `INVALID_INPUT` / `NOT_EVALUABLE` with a reason. Exactly zero-length paths and zero radii cannot receive a score. A tiny but strictly positive rational segment cannot be silently deleted or rejected by an arbitrary threshold. Any exact positive radius/length must be distinguished from zero by proved algebraic predicates, not by float heuristics.

**Single admitted nuisance domain:** `SO(2)` proper rotations only. Independent translation and strictly positive scale are removed deterministically by the two arclength centering/RMS normalizers. **No** reflection, reversal, cyclic shift, correspondence permutation, stroke assignment, free deformation, trimming, masks, rasterization, graph inference, time warp, additional scale fit, camera direction or physical optics. Do not select or change the nuisance group based on an input or numeric score. A separate future reversal/O(2) sensitivity needs its own signed scope and branch accounting.

**Scope labels:** `P0A3D_QO_2D_OPEN_RATIONAL_VERTEX_SO2_EXACT` is an independent generic mathematical lane; it is not `QO_A`, `QO_B`, QH or any source-attributed Hebrew observation.

## 2. Registered exact objective and target theorem

For a path `a`, let segment lengths be `l_i = sqrt((Δx_i)²+(Δy_i)²)` and total length `L_a = Σ_i l_i > 0`. Delete or explicitly bypass only exact zero-length consecutive segments while retaining their event log. Write `t_i=(Σ_{j<i} l_j)/L_a`. The continuous normalized-arclength map `a(u)`, `0 <= u <= 1`, is affine between successive exact algebraic breakpoints. Define analogously `b(u)`.

Let `c_a=∫_0^1 a(u)du`, `r_a²=∫_0^1 ||a(u)-c_a||²du >0`, `A(u)=(a(u)-c_a)/r_a`, and similarly `c_b,r_b,B`. Here every integral uses **the same normalized planar arclength parameter `du`**. Unit squared norms satisfy `∫||A||²du=∫||B||²du=1`.

Use `J(x,y)=(-y,x)` and define

`alpha = ∫_0^1 B(u)·A(u) du`,  `beta = ∫_0^1 B(u)·J(A(u)) du`.

The sole target objective is

`qO(a,b)=min_{Q∈SO(2)} [∫_0^1 ||Q A(u)-B(u)||² du]^(1/2)`.

Let `s = sqrt(alpha²+beta²)`. The target exact theorem is:

1. For every valid finite rational-coordinate pair, `alpha,beta,s,qO` and all entries of an optimal rotation matrix are **real algebraic numbers** with effectively decidable equality/order, and `0 <= s <= 1`.
2. The minimum is **attained** and `qO²=2-2s`; the exact nonnegative score is `sqrt(2-2s)`.
3. When `s>0`, the optimal proper rotation is specified algebraically by `cos θ=alpha/s` and `sin θ=beta/s`; its matrix is `[[alpha/s,-beta/s],[beta/s,alpha/s]]`, with determinant `+1`, and it realizes the computed residual. A decimal `atan2` angle is **not necessary** for a mathematically exact witness.
4. When `s=0` exactly, every proper planar rotation minimizes the residual; the canonical witness is identity, `qO=sqrt(2)`, and the status is `EXACT_WHOLE_ROLL_TIE`. A tiny-but-nonzero correlation must **never** be rounded into this case.
5. The input's entire `SO(2)` domain is covered by the analytic formula; there is no unexamined local optimization basin. Source/target input validity, piecewise arclength integration and all exact comparisons remain necessary premises.

**These are registered proof targets, not automatically proven software results.** The agent shall derive the proof line-by-line, identify any hidden hypothesis, and provide independently inspectable derivations. In particular, show constructively why rational-coordinate segment lengths, breakpoints, centered moments, `alpha,beta`, square roots, exact sign tests and equality tests stay in the ordered real-algebraic field. Describe effective root isolation/minimal-polynomial comparison (or a mathematically equivalent proven exact predicate), including zero testing and separation of algebraically equal values. A rational-segment-length shortcut **does not** establish the theorem for all rational-coordinate inputs.
